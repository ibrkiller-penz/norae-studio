# 노래공방 (Norae Studio)

내 컴퓨터의 그래픽카드로 노래를 만드는 AI 작곡 프로그램. 가사와 스타일을 적으면
반주와 노래가 함께 들어간 음원이 나온다. 인터넷에 곡을 보내지 않는다.

작곡은 오픈소스 모델 **YuE2**(`m-a-p/YuE2-3B` + `m-a-p/YuE2-Vae`)가 한다.
이 프로그램은 그 모델을 8GB 그래픽카드에서 돌아가게 감싸고, 설치·대기열·보관함을 맡는다.

## 필요한 것

| 항목 | 최소 | 비고 |
|---|---|---|
| 그래픽카드 | NVIDIA RTX 30 시리즈 이상 | BF16 연산이 필요하다(계산능력 8.0+). GTX 10/16, RTX 20 시리즈는 **안 된다** |
| 그래픽 메모리 | 8GB | 그 이하면 매우 느리거나 실패한다 |
| RAM | 16GB 권장 | |
| 디스크 | 20GB 여유 | 실행환경 3GB + 모델 8GB + 여유분 |
| 운영체제 | 윈도우 10/11 | |

Visual C++ 재배포 가능 패키지(x64)가 없으면 AI 엔진이 뜨지 않는다. 프로그램이
그 경우를 감지해서 안내한다.

## 쓰는 법

```bash
npm install
npm start
```

설치 파일(.exe)을 만들려면:

```bash
npm run dist
```

첫 실행에서 설치 화면이 뜬다. 두 가지 길이 있다.

1. **그대로 쓰기** — 이 컴퓨터에 이미 쓸 수 있는 AI 실행환경이 있으면
   (다른 YuE2 프로그램을 쓴 적이 있거나 예전에 설치했다면) 자동으로 찾아서
   **한 바이트도 받지 않고** 그걸 쓴다.
2. **설치 시작** — 약 11GB를 내려받는다. 10~40분.

## 만들어지는 파일이 어디 있나

| 무엇 | 어디 |
|---|---|
| 곡 | `문서\노래공방\<프로젝트>\<날짜_제목>\` |
| 설정·기록 | `%APPDATA%\NoraeStudio\settings.json`, `app.log` |
| 파이썬 실행환경 | `%APPDATA%\NoraeStudio\runtime\` (설치 위치를 바꿨으면 거기) |
| 모델 가중치 | `%USERPROFILE%\.cache\huggingface\` (표준 허깅페이스 캐시. 다른 AI 도구와 공유된다) |

## 어떻게 돌아가나

```
[Electron 창]  ←IPC→  [electron/main.js]  ←JSON 한 줄씩→  [python/worker.py]
 renderer/*             설치·대기열·파일                      YuE2 (GPU)
```

곡 하나는 네 단계를 거친다.

| 단계 | 하는 일 | 남기는 파일 |
|---|---|---|
| `plan` | 가사+스타일 → ABC 악보 | `plan/` |
| `semantic` | 악보 → 노래 토큰 | `semantic.npy` |
| `synth` | 토큰 → 잠재벡터 | `latent.npy` |
| `decode` | VAE 로 48kHz 24bit WAV | `audio.wav` |

각 단계 결과를 디스크에 남기기 때문에, 중간에 끊긴 곡은 보관함에서 눌러 **이어서 만들 수 있다**.
완성된 뒤에는 중간 파일을 지워 폴더를 정리한다.

### 예상 시간은 스스로 맞춰 간다

"남은 시간"이 맞으려면 이 컴퓨터가 얼마나 빠른지 알아야 한다. 값을 상수로 박아두면
그래픽카드가 다를 때 크게 어긋난다(RTX 3050 기준 값을 4060에서 쓰면 `semantic` 이 37% 빗나간다).

그래서 곡을 만들 때마다 단계별 실제 시간과 토큰 수를 재서 `settings.json` 의 `speed` 에 쌓고,
다음 추정에 쓴다. 표본이 적을 땐 크게, 8개가 넘으면 1/8씩만 움직인다. 두세 곡이면 맞아 든다.

- 모델 적재 시간은 `plan` 단계 안에서 일어나므로 따로 재서 빼낸다. 두 번째 곡부터는 적재가
  없으니 그 값은 건드리지 않는다.
- 이어 만들기로 건너뛴 단계는 시간을 잴 수 없으니 학습에서 제외한다.
- 화면은 늘 **보정 전** 토큰 예측을 함께 보낸다. 보정된 값을 보내면 비율이 1로 수렴해
  보정이 스스로 풀려버린다.
- 그래픽카드를 바꿨다면 설정에서 [측정값 초기화].

이 부분은 Electron 없이 돌아가는 순수 모듈(`electron/speed.js`)이라 따로 확인할 수 있다:

```bash
npm test
```

### 8GB 그래픽카드에서 돌리기 위한 것들

`python/worker.py` 가 YuE2 에 세 가지를 덧댄다. 이게 없으면 8GB 카드에서는 그냥 터진다.

- **메모리 상한 해제** — YuE2 는 CUDA 할당량을 (전체 − 2GiB)로 묶는다. 그 벽을 없앤다.
- **단계별 가중치 스왑** — AR 단계에는 필요한 층만, NAR 단계에는 전체를 GPU 에 올린다. 나머지는 CPU 에 둔다.
- **어텐션 패치** — 윈도우 PyTorch 에는 flash-attention 커널이 없고 memory-efficient 커널은
  grouped-query attention 을 거부한다. 그대로 두면 math 커널로 떨어져 호출당 ~4GiB 를 먹는다.
  K/V 를 펼쳐 빠른 커널을 유지하고, 쿼리를 1024씩 타일로 잘라 사용량 상한을 잡는다.

### 연주곡(가사 없는 곡)

프롬프트에 "instrumental" 이라고 적는 건 권유에 불과해서 모델이 그냥 노래를 부른다.
그래서 악보를 한 번 만든 뒤 **Vocal 성부의 음을 전부 쉼표로 바꾸고** 다시 계획한다.
부를 멜로디 자체가 없으니 노래가 나올 수 없다. 마디·길이·코드기호는 건드리지 않아 반주는 멀쩡하다.

## 바깥에 기대는 곳

이 프로그램이 인터넷을 쓰는 곳은 전부 원본 배포처다. 중간에 낀 서버가 없다.

| 무엇 | 어디서 |
|---|---|
| uv (파이썬 설치 도구) | `github.com/astral-sh/uv` |
| PyTorch (CUDA 12.8) | `download.pytorch.org` |
| YuE2 | `github.com/multimodal-art-projection/YuE` |
| 모델 가중치 | `huggingface.co` |
| 새 버전 확인 | **본인 GitHub 릴리스** (설정에서 바꾸거나 끌 수 있다) |

한 번 설치하고 나면 곡을 만들 때는 인터넷이 필요 없다. 위 주소들이 전부 사라져도
이미 설치된 실행환경으로 계속 돌아간다.

### 업데이트 설정

설정 창에서 `사용자명/저장소이름` 을 적어두면, 시작할 때 그 저장소의 최신 릴리스를 본다.
`npm run dist` 로 만든 `.exe` 를 릴리스 자산으로 올리면 프로그램이 그걸 받아 설치한다.

- 태그는 `v1.0.1` 처럼 붙인다. 현재 버전보다 높을 때만 알린다.
- **저장소가 비공개면 익명으로 받을 수 없다.** 그때는 조용히 넘어간다(프로그램 동작에는 지장 없음).
- 확인을 끄거나 저장소를 비우면 아예 접속하지 않는다.

## 파일 구조

```
electron/main.js      설치, 워커 관리, 대기열, 곡 폴더/MP3, 업데이트
electron/preload.js   화면에 열어주는 함수 목록 (여기 없는 건 화면에서 못 쓴다)
electron/updater.js   GitHub 릴리스 확인·다운로드
electron/speed.js     생성 속도 측정·학습 (순수 모듈)
electron/speed.test.js  위 모듈 확인 — `npm test`
renderer/index.html   화면 구조
renderer/styles.css   색과 배치
renderer/app.js       화면 동작 (프리셋, 진행률 추정, 보관함, 재생)
python/worker.py      YuE2 실행 + 저VRAM 패치
python/setup_models.py  모델 내려받기 (진행률 보고)
python/smoke_test.py  앱 없이 곡 하나 만들어 보는 확인용 스크립트
build/make-icon.mjs   icon.png 생성 (외부 꾸러미 없이)
```

## 확인하는 법

앱 없이 생성 경로만 확인하려면:

```bash
"%APPDATA%\ssokMusic\runtime\venv\Scripts\python.exe" -u python/smoke_test.py smoke-out
```

(자기 실행환경 경로로 바꿔서 쓴다. 단계별 시간과 완성된 파일 크기를 찍어 준다.)
